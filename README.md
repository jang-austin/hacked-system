# Hacked System Demo

A React application demonstrating the Nuclear Library components with stealth capabilities.

## Features

- 🔐 Login system with SessionStorage
- 🎨 10 colorful button components from Nuclear Library
- 🚨 Stealth PurpleButton with probability-based hacking simulation
- 📱 Responsive design
- 🎯 Educational security demonstration

## Live Demo

Visit the deployed application to see the Nuclear Library in action.

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Technologies Used

- React 18
- TypeScript
- Vite
- React Router
- Nuclear Library (@austinjang/nuclear-library)
